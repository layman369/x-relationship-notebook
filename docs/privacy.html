适用范围与独立性

本政策适用于 Chrome / Edge 扩展「X 关系簿」。本扩展为独立项目，与 X Corp. 没有隶属、认可或赞助关系。此政策说明扩展本身的数据处理；浏览器、X 和商店平台有各自的隐私政策。

处理哪些数据，以及用途

用户主动开始扫描后，扩展读取可访问的 X 页面中展示的用户名、昵称、头像图片链接、个人简介、关注和粉丝名单、个人主页公开的关注及粉丝人数。用途为展示资料、搜索与筛选、分析互关及未回关关系、比较粉丝快照。
用户添加的管理账号、标签、备注、忽略名单及过滤设置用于本机关系管理。用户提供的 JSON 备份可用于恢复本机数据或对比两个采集时间的关系记录。对比使用备份中的账号和名单时间，不根据文件名推断关注日期。
扩展记录名单更新时间及扫描摘要，包括开始/结束时间、扫描用时、采集人数、公开主页人数与结束原因，用于说明数据来源、进度及结果。扫描页面默认临时缩放至 25%，可由用户调整；任务结束或停止时尝试恢复此前缩放。
扩展不读取密码、Cookie 值、身份验证令牌、私信、支付信息、精确位置或无关网页的浏览历史，不提供自动关注、取关或私信。

存储位置与保留期限

扩展的名单、用户资料、标签、备注、忽略设置、粉丝快照及扫描摘要保存在当前浏览器配置文件的本机扩展存储中，不通过浏览器同步存储同步到云端。每个管理账号最多保留最近 30 次粉丝快照和最近 30 次扫描摘要；其他记录保留至用户替换、清理或卸载扩展。
当前扫描任务及进度保存在浏览器会话存储中，浏览器会话结束后不保证保留。用于时间对比的整份备份只在当前管理台页面内存中处理，刷新或关闭页面会清除已选择的对比备份。恢复备份则会按用户确认替换本机数据。
开发用 localhost 网页预览使用独立的网页本机存储，与已安装扩展的数据不互通。

网络请求与第三方服务

开发者不接收、托管或出售扩展内的关系名单、用户资料、备注或备份。扩展不包含广告、分析遥测、崩溃上报或远程执行代码。
扫描及打开个人主页时，浏览器会访问 x.com；这些请求使用浏览器已有的 X 登录会话，但扩展不读取登录凭据。展示头像时，会向 X 图片服务器 pbs.twimg.com 请求图片，从而向该服务披露网络请求通常包含的信息（例如 IP 地址和请求的图片地址）。头像请求设置不发送页面来源地址。扩展不把备注、忽略名单或备份上传到图片服务器。X 的服务受其自身政策约束：https://x.com/en/privacy 。因此，「不上传到开发者」不表示运行时完全没有网络请求。
用户选择打开 GitHub 项目、反馈问题或发送联系邮件时，相关服务会按其政策处理用户主动提供的信息。请勿在公开 Issues 中上传真实关系备份、私人备注或账号凭据。

用户控制与删除

用户可以自行决定是否扫描，可随时停止；可以修改备注标签、取消忽略、替换名单、导出 CSV 或整库 JSON 备份。导出文件由用户在本机保存，文件不是加密保险箱，分享前应自行核对内容。
要清除扩展在当前浏览器中的全部本机记录，可卸载扩展；浏览器管理的扩展存储会随之移除。此操作不会删除此前自行导出的文件、其他浏览器配置文件中的独立记录，或已经发送给他人的副本。开发用网页预览的数据需通过浏览器的站点数据管理单独清除。

有限使用与共享承诺

数据仅用于用户请求的关注关系管理、资料展示和备份对比。不出售数据，不将数据用于与扩展单一用途无关的目的，不用于广告定向、信用评估或放贷决策。开发者不会人工查看本机名单。扩展遵守 Chrome Web Store 用户数据政策及其中的 Limited Use 要求。

结果限制

未回关判断依赖名单完整性及用户名匹配，可能受到采集遗漏、账号改名、访问限制或 X 页面变化影响。两份记录中的相同关系只能给出观察间隔，不能证明两次之间关系持续不变，也不代表真实关注或回关日期。

政策更新与联系

数据处理方式变化时，会更新本政策及适用的商店声明，并标注日期。隐私问题可发送至 1917931073x@gmail.com ，或在项目 Issues 中仅提供不含私人数据的概要。

English summary

X Relationship Notebook is an independent extension maintained by layman369, not affiliated with X Corp. It processes user-requested, accessible X profile names, handles, biographies, avatar URLs, follower/following lists, public profile counts, user-entered notes/tags, ignored users, timestamps and scan summaries to manage relationships locally. Passwords, cookie values, authentication tokens, direct messages and unrelated browsing history are not read.
Lists and settings use local extension storage, not cloud sync. Up to 30 follower snapshots and 30 scan summaries per account are retained. Active progress uses session storage. A comparison backup is processed only in the manager page memory, while explicitly restoring a backup replaces stored data after confirmation.
The developer receives no extension records and provides no analytics or advertising. X page visits and image requests to pbs.twimg.com still occur and expose ordinary network request information to X; the extension does not send notes or backups to those services. Avatar requests omit the referring page URL. See https://x.com/en/privacy .
Users may stop scans, edit notes, replace lists and export their records. Uninstalling removes the browser-managed extension storage, but does not delete exported files or copies in other browser profiles. Data is not sold, used for unrelated purposes, advertising, creditworthiness or lending, and is handled in compliance with the Chrome Web Store User Data Policy, including Limited Use requirements.
Questions: 1917931073x@gmail.com . Public issue reports should not contain personal backups or credentials. Relationship durations represent observation intervals only, not exact follow dates or proof of uninterrupted relationships. This policy will be updated when practices change.
