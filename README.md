# X 关系簿

Chrome / Edge Manifest V3 扩展 0.13.0。支持一键自动扫描关注者和正在关注名单，分析未回关、互关及粉丝变化。无第三方依赖，无远程服务器，无远程上传。扫描通过浏览器内的后台协调器与页面脚本运行。

## 安装

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本项目目录（包含 manifest.json 的目录）。如果使用 zip，先解压并选择解压目录。
4. 将「X 关系簿」固定到工具栏。点击扩展中的「打开关系管理台」。

2026-10-30已确认0.12.0在Chrome商店公开发布；0.13.0可使用GitHub安装包。网页预览与扩展使用独立存储，彼此不会同步。

升级：已加载本项目目录的用户，在扩展管理页点击「重新加载」；如浏览器提示新增 X 页面访问权限，确认后启用。已有名单、备注和快照继续使用原有存储格式。最低 Chrome / Chromium 版本为 120。

## 数据入口 A：导入名单

在管理台添加自己的 X 用户名，导入「正在关注」和「关注者 / 粉丝」。每行一个用户名，或使用以下 JSON 用户数组：

```json
[
  { "handle": "example", "name": "示例昵称" },
  { "handle": "another_user", "name": "另一个示例" }
]
```

仅当名单确实包含全部用户时勾选「完整名单」。默认替换所选名单；合并导入会标记为部分名单。此格式是本扩展的名单格式，尚不直接解析 X 官方归档文件。

## 数据入口 B：一键扫描

1. 在当前浏览器登录 X，打开扩展弹窗或关系管理台。
2. 输入目标用户名。弹窗在 X 个人主页或标准名单页上打开时，会尝试预填该用户名。
3. 点击「扫描两份名单」，或选择「仅扫描关注者」「仅扫描正在关注」。会新建一个 X 标签页，从顶部开始自动滚动；双名单任务先扫描关注者，再切换到正在关注。
4. 右侧进度面板和扩展界面显示已收集人数。关闭扩展弹窗不会停止扫描，请保持扫描标签页打开，尽量保持该标签页可见，避免后台节流。
5. 点击右侧面板或扩展中的「停止扫描」随时结束，保留已确认写入的部分名单。关闭或刷新扫描标签页也会中断。
6. 到达底部且约 12 秒没有新增，标记为「待核对」。每份名单最多 10000 人或 10 分钟；停滞约 30 秒会结束该份名单。双名单任务在停滞或达到上限后仍尝试另一份，用户停止或错误则终止整个任务。
7. 到管理台核对名单，仅在核实无遗漏后手动确认完整，再使用未回关分析与粉丝快照。零用户、未公开名单或未识别的页面不会自动认定为空且完整。

每份名单首次识别到用户时，替换对应旧名单；之后增量去重写入，原来的标签备注和粉丝快照保留。建议开始前备份；没有识别到任何用户时保留旧名单，并提示不能确认空列表。所有扫描结果默认为部分名单，扫描不会自动保存粉丝快照。用户名匹配不等于稳定用户 ID。

扫描只读取页面中可访问的用户名、昵称、头像链接和个人简介，不调用 X 私有 API，不读取密码、Cookie 或令牌，不操作关注、取关或私信。主内容区名单之外的侧边栏卡片不采集。X 的列表裁剪、推荐混入、限流、延迟加载及页面结构变化都可能影响结果，需要用户核对。当前仅支持标准 following / followers，不支持 verified_followers 等变体，也不能读取没有访问权限的账号名单。真实登录的 X 页面仍待验收。

同一时间只运行一个扫描。浏览器重启不会自动恢复未完成扫描，已写入名单保留；任务进度只保留在当前浏览器会话中。进度超过两分钟无更新，再次打开扩展查询状态时会提示中断。

右侧进度：点击扫描时会打开浏览器原生侧边栏，也可点击「打开右侧进度」单独打开。侧边栏与 X 页面独立，显示正常字号的扫描状态、两份名单人数、最近 50 条已采集用户、本次扫描记录和停止按钮。切换 X 名单或关闭弹窗后，侧边栏仍可保持显示；关闭侧边栏不会停止扫描。默认显示在右侧，实际位置遵循浏览器的侧边栏位置偏好。原生侧边栏无法在 localhost 网页预览中打开，网页预览可访问 /sidepanel.html 查看界面。

扫描缩放：默认临时缩小到 25%，可选择 50%、67%、80% 或保持原比例。缩小页面可让视口容纳更多用户卡片，但实际加载数量仍由 X 决定。仅修改扫描标签页，不修改 X 网站的持久缩放设置。双名单切换后重新应用所选比例，结束、停止、错误或超时处理时恢复该份扫描开始前的比例。缩放失败时按原比例继续，并在进度区提示。浏览器重启、扩展重载或浏览器拒绝恢复时可能无法立即自动还原，可手动调整；Ctrl+0 恢复默认 100%，不一定是此前的自定义比例。

## 关系规则

- 同时出现在关注和粉丝名单中：已确认互关。
- 在关注名单中，但不在**完整粉丝名单**中：未回关我。
- 在粉丝名单中，但不在**完整关注名单**中：我未回关。
- 另一侧名单不完整：关系待确认。

这些结论只反映当前保存的名单。页面显示的是「已收集」人数，非实时官方总数。两侧名单宜在相近时间更新。

## 粉丝变化

粉丝名单标记完整后，进入「粉丝变化」保存快照。首次建立基线，第二次起对比最近两次快照，最多保存 30 次。每次先替换成新一轮完整名单，再保存快照。

新增表示出现在新快照，消失表示不再出现在新快照；消失可能来自取关、改名、封禁或名单遗漏，不等同于已证实取关。当前按用户名匹配，不具有稳定的 X 用户 ID，因此无法跨改名识别同一人，也无法回溯安装前的历史。

## 其他功能

搜索用户名、昵称、简介、标签、备注；导出当前筛选结果为 CSV；整库 JSON 备份与恢复；多账号隔离。统计卡片可直接切换关注、粉丝、互关和未回关名单。用户列表支持 20 / 50 / 100 / 200 条分页，默认为每页 20 条，支持首页、末页和页码跳转。列表卡片按窗口高度分配可视区域，数据区域内部滚动，表头及分页栏保持可见；切换账号、分类、搜索或每页条数时回到第一页。CSV 导出包含全部筛选结果。恢复备份前会要求确认替换，建议先备份。扫描期间暂时禁用名单导入、恢复和完整性确认。备注编辑与扫描写入通过锁串行化，避免相互覆盖。已移除内置演示数据；首次使用新版会定向清除旧版内置的 demo_account，其余账号名单、备注和快照保留。

数据存于 chrome.storage.local，网页预览用 localStorage。没有加密或云同步，卸载扩展可能丢失数据，请定期备份。头像保存为 X 图片服务器的 HTTPS 链接，显示时会向 pbs.twimg.com 请求图片，不下载为本机图片文件；不发送页面来源信息。头像无法访问时使用文字占位。主页链接由用户点击后打开 X。大名单会受浏览器存储配额和页面渲染性能限制，当前首版未针对超大账号优化。

权限为 storage、scripting、sidePanel，以及 https://x.com/*、https://www.x.com/* 的页面访问权限。X 域访问用于在用户发起任务后打开名单并注入扫描脚本；没有其他网站访问权限。X 页面加载后有一个轻量脚本通知后台“文档就绪”，没有任务时不采集卡片或滚动页面。真正的扫描只在用户发起任务且目标文档匹配后启动。点击扫描时若 X 权限被收回，会请求用户重新授予；拒绝后不会打开扫描标签页。Chrome 脚本与权限说明：
https://developer.chrome.com/docs/extensions/reference/api/scripting

不提供批量自动关注或取关。可打开个人主页由用户自行处理。X 规则：
https://help.x.com/en/rules-and-policies/x-automation
